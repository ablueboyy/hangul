# 韓文字母練習 한글

一個學韓文 40 個字母（자모）的 PWA。用 Vite + React + TypeScript + Tailwind 寫的純前端，
可以裝到 iPhone 主畫面當成 App 用，也可以離線使用。

## 學習流程

字母分成 **8 組、每組 5 個**，全部開著：在「課程」勾要練哪幾組（可複選），練習只會出勾到的字母。

```
入門(0–2分)  →  認識(3–5分)  →  精通(6分)
```

- 每答對一題，該題考到的字母 **+1 分**；答錯 **−1 分**（不會低於 0）
- 勾選結果記在 `localStorage` 的 `hangul.letters.groups.v1`；第一次打開時，會預設勾選以前闖關制解鎖到的那幾組

建議的順序是先把 10 個基本母音學完再進子音。母音要單獨寫成字得配一個不發音的 `ㅇ`
（`ㅏ` → `아`），所以只勾第一組也能出「這個字怎麼念」的題目。

| 組 | 字母 | 重點 |
| -- | ---- | ---- |
| 1 | ㅏ ㅑ ㅓ ㅕ ㅗ | 基本形 + 一畫 = 加上 y 的音 |
| 2 | ㅛ ㅜ ㅠ ㅡ ㅣ | 基本母音收齊 |
| 3 | ㄱ ㄴ ㄷ ㄹ ㅁ | 開始拼出真正的字 |
| 4 | ㅂ ㅅ ㅇ ㅈ ㅎ | 基本子音收齊 |
| 5 | ㅊ ㅋ ㅌ ㅍ ㅐ | 送氣音 |
| 6 | ㅒ ㅔ ㅖ ㅘ ㅙ | 複合母音 (一) |
| 7 | ㅚ ㅝ ㅞ ㅟ ㅢ | 複合母音 (二) |
| 8 | ㄲ ㄸ ㅃ ㅆ ㅉ | 雙子音（緊音） |

## 題型

出題引擎（`src/lib/quiz.ts`）**只會用勾選的字母**（干擾選項也是），每題都有唯一正確答案，並標記自己考到哪幾個字母。
只勾子音的時候會借幾個基本母音來拼字，借來的母音不計分：

| 題型 | 樣子 |
| ---- | ---- |
| 字母 → 拼音 | `ㄷ` → d |
| 拼音 → 字母 | 「eu」→ `ㅡ` |
| 聽音辨字 | 🔊 → `ㅕ`（播的是字母的音，不是字母的名字） |
| 音節 → 拼音 | `며` → myeo |
| 拼音 → 音節 | 「ra」→ `라` |
| 拆字 | `유` → `ㅇ + ㅠ` |

干擾選項刻意只換掉子音或只換掉母音（`더 / 뎌 / 댜 / 듀`），逼你真的分辨差在哪。
拼字題一次會考到子音和母音兩個字母，所以一題賺兩份分數。

一輪 12 題。

## 分頁

底部只放四個：**期中考／單字／字母表／更多**。字母課程（含字母練習）、聽寫、進度與備份收在「更多」裡。

| 分頁 | 內容 |
| ---- | ---- |
| **期中考** | 照考卷題型複習，見下一節 |
| **單字** | 學校課程每週的單字庫。勾週數（可複選）→ 選擇題測驗 |
| **字母表** | 40 個字母全景，點下去聽發音、看發音重點。上方「對比聽」可以自選最多 6 個字母連著念 |
| **更多 → 字母課程** | 勾要練哪幾組、各字母的分數、「先認識字母」教學頁（含拼字盤）、字母練習 |
| **更多 → 聽寫** | 念一個字 → 手寫 → 自己改。單字模式勾週數；字母模式勾字母和收音 |
| **更多 → 進度** | 精通數、連續天數、正確率、最該補的字母、外觀、備份與還原 |

## 期中考

範圍與資料在 `src/data/exam.ts`（單字範圍 `EXAM_LAST_WEEK`、字母順序、造句），出題在 `src/lib/exam.ts`。
每題可以**手寫後自己對答案**，或用**韓文鍵盤打字自動改**（最上面切換）。

| 區塊 | 題型 |
| ---- | ---- |
| 單字 | 漢字語：給漢字寫韓文和中文意思・外來語：給英文寫韓文・固有語：給中文寫韓文。分類看 `vocab.ts` 的 `hanja` / `en` 欄位，都沒有就是固有語 |
| 聽力 | 念單字或單一個字（40 個字母現場拼、可帶收音），寫下來 |
| 造句 | 看中文／英文寫韓文句子。有的句型會換名詞；打字模式忽略空格和標點，但空格不一樣會提醒 |
| 字母順序 | 整排默寫（基本母音 10、基本子音 14、硬音 5、複合母音 11、終聲 7），或一排挖一格。順序表標的是課堂拼音 |

答錯的題目會進**錯題本**（`localStorage` 的 `hangul.exam.v1`，不進備份碼），答對就移除。
打字默寫字母時，iPhone 鍵盤會把連打的子音黏成 ㄻ 之類，對答案前會自動拆回來。

造句也有發音檔：`make_audio.py` 會用 node 直接載入 `exam.ts` 列出所有句子，所以 `exam.ts` 不能 import 別的檔案。

## 每週單字

`src/data/vocab.ts` 放學校課程 16 週的單字，每個字有韓文、羅馬字、中文意思。
和字母那套分開記分，操作方式一樣 —— 想練哪幾週就在「單字」分頁勾哪幾週
（可複選，勾選結果記在 `localStorage` 的 `hangul.vocab.weeks.v1`），只有勾到的字會進測驗。

出題引擎是 `src/lib/vocabQuiz.ts`，四種題型：

| 題型 | 樣子 |
| ---- | ---- |
| 看字選意思 | `오이` → 小黃瓜 |
| 看意思選字 | 「小黃瓜」→ `오이` |
| 聽音選字 | 🔊 → `오이` |
| 聽音選意思 | 🔊 → 小黃瓜 |

**干擾選項只從被勾選的那幾週裡抽**，所以你分辨的是真正會考的那批字，不會拿沒學過的字來墊檔。
一輪最多 12 題，字少的時候題數跟著減（`sessionSize`），不然會一直重複同一個字。
熟練度和字母一樣是 0～6 分，答對 +1 答錯 −1，分數低的字比較容易被抽到。

要加新的一週：把單字填進 `vocab.ts` 對應的 `week`，然後跑 `npm run audio` 補發音檔。
⚠️ 已經上線的週次**不要改順序或刪字**，備份碼是照「第幾週的第幾個字」的位置存分數的。

## 發音

發音用的是專案內建的音檔（`public/audio/`，約 480 個 mp3、共 2MB；另外 `public/audio/final/` 是聽寫用的 2786 個帶收音音節、12MB，不進安裝包，由 App 在背景下載快取），不是瀏覽器內建的語音合成。
原因是語音合成在各裝置上差太多：系統沒裝韓文語音時，瀏覽器會拿英文或中文語音去硬念韓文字，
念出來的東西跟那個字母毫無關係。改成內建音檔之後，每台裝置聽到的完全一樣，離線也能用。
語音合成只留著當萬一的後備（而且沒有韓文語音時寧可不出聲，也不要念出誤導人的音）。

音檔用 [edge-tts](https://github.com/rany2/edge-tts) 的 `ko-KR-SunHiNeural` 產生 —— 免費、不用帳號、
不用 API key，而且只在產音檔時跑一次，執行時什麼服務都不需要：

```bash
pip install edge-tts
npm run audio          # = python scripts/make_audio.py
```

內容是 19 初聲 × 21 中聲 = 399 個音節、40 個字母名稱、40 個例詞。已經存在的檔案會跳過，
要整批重產就加 `--force`，換聲音就加 `--voice ko-KR-InJoonNeural`。
edge-tts 回傳的音檔前後有一大段靜音，腳本會照 mp3 的幀邊界裁掉，檔案因此小掉六成。

### 字母的「音」和「名字」是兩回事

這是韓文字母最容易踩的坑：`ㄱ` 的名字叫 **기역**（gi-yeok），但它的音是 g/k；`ㅅ` 叫 **시옷**，
音卻是 s。拿名字去發音，聽到的跟字母根本對不起來。所以子音一律用代表音節示範
（`ㄱ → 가`、`ㅅ → 사`、`ㄲ → 까`，就是韓國人自己學字母的 가나다라마바사），
存在 `hangul.ts` 的 `sound` 欄位；母音的名字本來就等於它的音，不需要另外標。
介面上兩者分開呈現：大的是音，旁邊小字才是名字。

`ㅇ` 在字首不發音，所以它不會出聽力題 —— 沒有東西可以聽。

## 配色

兩套主題，可在 header 的小按鈕或「進度 → 外觀」切換：**跟隨系統 / 丹青（淺）/ 深夜（深）**，
選擇存在 `localStorage`（key: `hangul.theme.v1`）。

- **深夜** — 深藍灰底配天藍
- **丹青** — 韓紙米底（`#f4efe3`）配韓國傳統建築彩繪的青綠（`#1c5f6b`）與朱紅（`#c0392b`）

顏色一律走 `src/index.css` 裡的語意化 token（`page` / `surface` / `ink` / `accent` / `ok` / `bad` / `warn` …），
元件裡不再出現 `bg-slate-800` 這種寫法。要加第三套配色，就再複製一個 `[data-theme="..."]` 區塊
覆蓋那些變數即可，不用動任何元件。

`index.html` 有一段行內腳本在第一次繪製前就決定主題，避免深色閃一下才跳成淺色 ——
它和 `src/hooks/useTheme.ts` 共用同一個 storage key，改的時候要一起改。

所有文字／背景組合都通過 WCAG AA（4.5:1，次要文字 3:1）。

## 開發

```bash
npm install
npm run dev            # http://localhost:5173
npm run dev -- --host  # 同網段的 iPhone 也能連進來測
npm run build          # 型別檢查 + 打包到 dist/
npm run preview        # 預覽打包結果
npm run lint
npm run icons          # 重新產生 public/ 底下的 PWA icon
```

## 在 iPhone 上使用

1. Safari 開啟網址（本機測試就開 `npm run dev -- --host` 印出的那個區網位址）
2. 下方分享鈕 →「加入主畫面」
3. 之後從主畫面點開就是全螢幕、沒有網址列，也能離線用

**更新不用刪掉重加。** 推新版上去之後，下次切回 App 它會自己抓新版並重新整理
（`src/lib/pwa.ts`，每次回到前景都檢查一次）。進度存在 `localStorage`，跟著網址走，
更新完都還在 —— 反而是**把主畫面圖示刪掉重加會清掉進度**，千萬別這樣更新。
「進度」頁最底下的版本時間可以用來確認手機上已經是新版。

> 發音是內建音檔，不需要在系統裡裝任何韓文語音。iOS 只有一個限制：第一次播放必須發生在
> 使用者的觸控裡，App 已經在第一次點擊時處理掉了。
>
> 區網 http 測試時「加入主畫面」可以用，但離線快取要 https 才會生效。

## 部署到 GitHub Pages

推到 GitHub 之後：

1. Repo → **Settings → Pages → Source** 選 **GitHub Actions**
2. 推一次 `main`，`.github/workflows/deploy.yml` 會自動建置並部署
3. 網址是 `https://<你的帳號>.github.io/<repo 名稱>/`

`vite.config.ts` 的 `base` 讀環境變數 `BASE_PATH`，workflow 已經自動帶入 repo 名稱，
本機開發則維持 `/`。

## 進度存在哪 / 備份

全部存在瀏覽器的 `localStorage`（key: `hangul.progress.v2`），不會上傳到任何地方，
所以換裝置或換瀏覽器不會同步。開啟時會呼叫 `navigator.storage.persist()` 要求持久化，
但成不成功由瀏覽器決定。

⚠️ **iOS 的 7 天規則**：留在 Safari 分頁裡的網站，7 天沒互動 localStorage 就會被清掉
（iOS 13.4 起的 ITP 政策）。**加到主畫面**的 web app 不受這個限制 —— 所以要長期練就一定要加到主畫面。

真正的保險是「進度」分頁裡的 **備份與還原**：

- **匯出備份碼** — 產生一段文字（`HG2-0000...-1-0-0-0-0--vtxn`），複製或用系統分享存到備忘錄
- **還原進度** — 貼回去，先顯示「要還原成什麼」再確認覆蓋

備份碼帶檢查碼，貼一半或改到內容會直接被擋下來，不會安靜地載入一份壞掉的進度。
編碼實作在 `src/lib/backup.ts`：`HG2` 比舊的 `HG1` 多一段單字分數（每週一段、用 `.` 隔開，
尾端全 0 的週次會省略），**舊的 HG1 備份碼還是讀得進來**，單字進度當作全新開始。
裡面的 `BACKUP_ORDER` 和 `vocab.ts` 的週次／字序 **都不能重排**，否則舊備份碼會對到錯的東西。
