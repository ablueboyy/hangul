# 韓文字母練習 한글

一個學韓文 40 個字母（자모）的 PWA，闖關解鎖制。用 Vite + React + TypeScript + Tailwind 寫的純前端，
可以裝到 iPhone 主畫面當成 App 用，也可以離線使用。

## 學習流程

字母分成 **8 組、每組 5 個**，一組一組解鎖：

```
未解鎖  →  入門(0–2分)  →  認識(3–5分)  →  精通(6分)
```

- 每答對一題，該題考到的字母 **+1 分**；答錯 **−1 分**（不會低於 0）
- 目前這一組 5 個字母 **全部到精通**，才會解鎖下一組
- 已解鎖的組不會再上鎖 —— 舊字母複習答錯只會掉分提醒你回頭補，不影響已開的關

分組順序是先把 10 個基本母音學完再進子音。母音要單獨寫成字得配一個不發音的 `ㅇ`
（`ㅏ` → `아`），所以第一組就能出「這個字怎麼念」的題目；`ㅇ` 本身要到第 4 組才正式解鎖計分。

| 組 | 字母 | 重點 |
| -- | ---- | ---- |
| 1 | ㅏ ㅑ ㅓ ㅕ ㅗ | 基本形 + 一畫 = 加上 y 的音 |
| 2 | ㅛ ㅜ ㅠ ㅡ ㅣ | 基本母音收齊 |
| 3 | ㄱ ㄴ ㄷ ㄹ ㅁ | 開始拼出真正的字 |
| 4 | ㅂ ㅅ ㅇ ㅈ ㅎ | 基本子音收齊 |
| 5 | ㅊ ㅋ ㅌ ㅍ ㅐ | 送氣音 |
| 6 | ㅒ ㅔ ㅖ ㅘ ㅙ | 複合母音 (一) |
| 7 | ㅚ ㅝ ㅞ ㅟ ㅢ | 複合母音 (二) |
| 8 | ㄲ ㄸ ㅃ ㅆ ㅉ | 雙子音（緊音） |

## 題型

出題引擎（`src/lib/quiz.ts`）**只會用已解鎖的字母**，每題都有唯一正確答案，並標記自己考到哪幾個字母：

| 題型 | 樣子 |
| ---- | ---- |
| 字母 → 拼音 | `ㄷ` → d |
| 拼音 → 字母 | 「eu」→ `ㅡ` |
| 聽音辨字 | 🔊 → `ㅕ`（沒有韓文語音時自動跳過） |
| 音節 → 拼音 | `며` → myeo |
| 拼音 → 音節 | 「ra」→ `라` |
| 拆字 | `유` → `ㅇ + ㅠ` |

干擾選項刻意只換掉子音或只換掉母音（`더 / 뎌 / 댜 / 듀`），逼你真的分辨差在哪。
拼字題一次會考到子音和母音兩個字母，所以一題賺兩份分數。

一輪 12 題，全對的話大約 3 輪（27～37 題）解鎖下一組。

## 四個分頁

| 分頁 | 內容 |
| ---- | ---- |
| **課程** | 8 組的解鎖狀態、目前這組每個字母的分數與等級、「先認識字母」教學頁（含拼字盤）、「練習」 |
| **練習** | 練這一組 / 複習全部已解鎖。答完即時顯示對錯、加減分與解說 |
| **字母表** | 40 個字母全景，未解鎖的打上 🔒 並告訴你在第幾組 |
| **進度** | 精通數、連續天數、總正確率、字母分布、現在最該補的字母 |

發音用瀏覽器內建的語音合成（`ko-KR`），所以專案裡不需要放任何音檔。

## 開發

```bash
npm install
npm run dev            # http://localhost:5173
npm run dev -- --host  # 同網段的 iPhone 也能連進來測
npm run build          # 型別檢查 + 打包到 dist/
npm run preview        # 預覽打包結果
npm run lint
npm run icons          # 重新產生 public/ 底下的 PWA icon
```

## 在 iPhone 上使用

1. Safari 開啟網址（本機測試就開 `npm run dev -- --host` 印出的那個區網位址）
2. 下方分享鈕 →「加入主畫面」
3. 之後從主畫面點開就是全螢幕、沒有網址列，也能離線用

> 發音需要系統裝有韓文語音。iPhone 若沒聲音，到
> **設定 → 輔助使用 → 朗讀內容 → 聲音 → 韓文** 下載一次即可。沒有語音時聽力題會自動不出現。
>
> 區網 http 測試時「加入主畫面」可以用，但離線快取要 https 才會生效。

## 部署到 GitHub Pages

推到 GitHub 之後：

1. Repo → **Settings → Pages → Source** 選 **GitHub Actions**
2. 推一次 `main`，`.github/workflows/deploy.yml` 會自動建置並部署
3. 網址是 `https://<你的帳號>.github.io/<repo 名稱>/`

`vite.config.ts` 的 `base` 讀環境變數 `BASE_PATH`，workflow 已經自動帶入 repo 名稱，
本機開發則維持 `/`。

## 進度存在哪 / 備份

全部存在瀏覽器的 `localStorage`（key: `hangul.progress.v2`），不會上傳到任何地方，
所以換裝置或換瀏覽器不會同步。開啟時會呼叫 `navigator.storage.persist()` 要求持久化，
但成不成功由瀏覽器決定。

⚠️ **iOS 的 7 天規則**：留在 Safari 分頁裡的網站，7 天沒互動 localStorage 就會被清掉
（iOS 13.4 起的 ITP 政策）。**加到主畫面**的 web app 不受這個限制 —— 所以要長期練就一定要加到主畫面。

真正的保險是「進度」分頁裡的 **備份與還原**：

- **匯出備份碼** — 產生一段約 70 字的文字（`HG1-0000...-1-0-0-0-0-vtxn`），複製或用系統分享存到備忘錄
- **還原進度** — 貼回去，先顯示「要還原成什麼」再確認覆蓋

備份碼帶檢查碼，貼一半或改到內容會直接被擋下來，不會安靜地載入一份壞掉的進度。
編碼實作在 `src/lib/backup.ts`，裡面的 `BACKUP_ORDER` **不能重排**，否則舊備份碼會對到錯的字母。
